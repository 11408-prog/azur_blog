# hexo
**Q: tags和categories有什么区别**<br>
A:tags表示关键词和特征，categories表示大方向和目录。tags不需要事先定义，但是categoties需要事先定义


**Q:有时会出现tags: 或者其它类似物下一行明明是空行却报错，该怎么办**<br>
A:记得：之后要空格

# css
**Q: forwards和infinite有什么区别**<br>
A:前者会使动画停在最后一帧，后者会使动画无限播放
对比：
```bash
/* 只播放一次，结束后停在最后一帧 */
animation-name: welcome-reveal;
animation-duration: 6s;
animation-timing-function: ease-in-out;
animation-fill-mode: forwards;

/* 无限循环播放 */
animation-name: welcome-reveal;
animation-duration: 6s;
animation-timing-function: ease-in-out;
animation-iteration-count: infinite;
```

如果在 github 中设置了 CI/CD 只需要提交即可，github会帮忙完成部署 

# python
**Q: " "和' '有什么区别吗**<br>
A:完全没有区别

**Q: >>> 是什么意思，可以被编译器读取吗**<br>
A:是py交互式解释器（REPL）显示给用户看的。不能被编译器读取，这不是有效语法。

# 计算机网络

**Q:互联网和互连网是更大的计算机网络吗**<br>
A:这个说法不严谨。因为互连网有时候要比计算机网络小，如一个庞大的城域网规模要远超一个家庭网络。可以这么理解，互连网是计网组合后的通用结果，互联网是计网组合后的特定结果。
