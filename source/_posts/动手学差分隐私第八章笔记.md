# 第八章：近似差分隐私（Approximate Differential Privacy）笔记

## 8.1 近似差分隐私定义

### 定义

近似差分隐私，也叫 $(\epsilon, \delta)$-差分隐私，定义如下：

$$
\Pr[F(x) \in S] \le e^\epsilon \Pr[F(x') \in S] + \delta
$$

其中：

- $F$ 是随机化机制；
- $x, x'$ 是相邻数据集；
- $S$ 是任意输出集合；
- $\epsilon$ 是隐私预算；
- $\delta$ 是失败概率。

### 含义

- 以概率 $1-\delta$，机制提供与纯 $\epsilon$-DP 相同的保证；
- 以概率 $\delta$，机制可能不提供任何保证。

$\delta$ 通常要求非常小，比如 $1/n^2$ 或更小，其中 $n$ 是数据集大小。

### 与纯 $\epsilon$-DP 的关系

纯 $\epsilon$-DP 是 $(\epsilon, 0)$-DP 的特例。  
因此，拉普拉斯机制等满足纯 $\epsilon$-DP 的机制，也可以写成 $(\epsilon, 0)$-DP。

$$
\text{纯 } \epsilon\text{-DP} \equiv (\epsilon, 0)\text{-DP}
$$

纯 DP $\subset$ 近似 DP。

## 8.2 近似差分隐私的性质

### 8.2.1 顺序组合

如果：

- $F_1(x)$ 满足 $(\epsilon_1, \delta_1)$-DP；
- $F_2(x)$ 满足 $(\epsilon_2, \delta_2)$-DP；

那么同时发布两个结果 $G(x) = (F_1(x), F_2(x))$ 满足：

$$
(\epsilon_1 + \epsilon_2,\ \delta_1 + \delta_2)\text{-DP}
$$

注意：不仅 $\epsilon$ 相加，$\delta$ 也相加。

### 8.2.2 后处理

如果 $F(X)$ 满足 $(\epsilon, \delta)$-DP，那么对任意确定性或随机函数 $g$，$g(F(X))$ 仍满足 $(\epsilon, \delta)$-DP。

后处理不会增加隐私损失，$\delta$ 也不会因后处理而变大。

### 8.2.3 并行组合

如果数据集被分成不相交的子集 $x_1, \dots, x_k$，并在每个子集上分别运行满足 $(\epsilon_i, \delta_i)$-DP 的机制 $F_i$，则整体满足：

$$
\left(\max_i \epsilon_i,\ \max_i \delta_i\right)\text{-DP}
$$

即 $\epsilon$ 和 $\delta$ 都取最大值，不累加。  
如果所有子机制参数相同，则整体仍为同一个 $(\epsilon, \delta)$。

## 8.3 高斯机制

### 定义

高斯机制是近似差分隐私下的核心机制之一。对于函数 $f(x)$，敏感度为 $s$（向量值函数通常用 L2 敏感度），高斯机制定义为：

$$
F(x) = f(x) + \mathcal{N}(\sigma^2)
$$

其中噪声方差取：

$$
\sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2}
$$

这里 $\log$ 是自然对数。在此参数下，$F$ 满足 $(\epsilon, \delta)$-DP。

通常要求 $\epsilon \le 1$（高隐私场景）。

### 为什么高斯机制不满足纯 $\epsilon$-DP？

考虑两个相邻数据集对应的高斯输出分布：

$$
Y \sim \mathcal{N}(\mu, \sigma^2),\qquad Y' \sim \mathcal{N}(\mu', \sigma^2)
$$

密度比为：

$$
\frac{p_Y(y)}{p_{Y'}(y)} = \exp\left( \frac{(y-\mu')^2 - (y-\mu)^2}{2\sigma^2} \right)
$$

展开平方差：

$$
(y-\mu')^2 - (y-\mu)^2 = 2y(\mu-\mu') + (\mu'^2-\mu^2)
$$

其中含有 $2y(\mu-\mu')$，当 $y \to \pm\infty$ 时，这一项线性增长，密度比无全局上界。  
因此不存在有限的 $\epsilon$ 使密度比处处 $\le e^\epsilon$，所以高斯机制不满足纯 $\epsilon$-DP。

### 与拉普拉斯机制对比

拉普拉斯机制密度比：

$$
\frac{p(y-\mu)}{p(y-\mu')} = \exp\left( \frac{|y-\mu'| - |y-\mu|}{b} \right)
$$

由三角不等式：

$$
|y-\mu'| - |y-\mu| \le |\mu-\mu'| \le s
$$

取 $b = s/\epsilon$，则密度比 $\le e^\epsilon$，与 $y$ 无关。  
因此拉普拉斯机制满足纯 $\epsilon$-DP。

**关键区别**：

- 拉普拉斯机制利用绝对值三角不等式，把 $y$ 消掉，得到全局上界；
- 高斯机制平方差展开后 $y$ 消不掉，无全局上界。

### 优雅失败

高斯机制以概率 $\delta$ 不满足承诺的 $\epsilon$-DP，但输出始终是 $f(x) + \mathcal{N}(0,\sigma^2)$，不会返回原始数据。  
失败时，只是某些极端输出上的密度比超过 $e^\epsilon$，实际隐私参数从 $\epsilon$ 变为稍大的 $\epsilon'$，但噪声仍然存在，隐私没有完全丧失。  
这种失败称为“优雅失败”。

与灾难机制对比：灾难机制以概率 $\delta$ 直接返回整个原始数据集，隐私完全丧失。

### 与随机响应机制的区别

| 维度 | 随机响应 | 高斯机制 |
|------|----------|----------|
| 隐私模型 | 本地模型 | 中心模型 |
| 谁加噪 | 数据主体本地 | 可信数据管理者 |
| 数据类型 | 二值、分类 | 数值、向量 |
| 输出 | 离散类别 | 连续实数或向量 |
| 隐私定义 | 通常纯 $\epsilon$-DP | $(\epsilon, \delta)$-DP |
| $\delta$ 角色 | 通常无 $\delta$ | 失败概率，影响噪声方差 |
| 随机化方式 | 按概率翻转/随机回答 | 加高斯噪声 |

## 8.4 向量值函数与敏感度

### 为什么需要向量值函数

很多查询返回向量，例如直方图返回每个 bin 的计数。  
拉普拉斯机制和高斯机制都可扩展到向量值函数 $f: \mathcal{D} \to \mathbb{R}^k$。

### L1 范数与 L2 范数

对于向量 $V = (v_1, \dots, v_k)$：

- L1 范数：$\|V\|_1 = \sum_{i=1}^k |v_i|$
- L2 范数：$\|V\|_2 = \sqrt{\sum_{i=1}^k v_i^2}$

同一个向量，L1 和 L2 值不同。  
例如全 1 向量长度 $k$：L1 = $k$，L2 = $\sqrt{k}$。

### L1 敏感度与 L2 敏感度

- L1 敏感度：$GS_1(f) = \max_{d(x,x')\le 1} \|f(x)-f(x')\|_1$  
  等于各元素敏感度之和。若每个元素敏感度为 1，长度 $k$ 的向量 L1 敏感度为 $k$。
- L2 敏感度：$GS_2(f) = \max_{d(x,x')\le 1} \|f(x)-f(x')\|_2$  
  若每个元素敏感度为 1，长度 $k$ 的向量 L2 敏感度为 $\sqrt{k}$。

高维时 $\sqrt{k} \ll k$。

### 机制选择

- 向量拉普拉斯机制：需要 L1 敏感度，噪声尺度 $s/\epsilon$，$s$ 为 L1 敏感度。
- 向量高斯机制：可使用 L1 或 L2 敏感度，噪声方差 $\sigma^2 = \frac{2s^2 \log(1.25/\delta)}{\epsilon^2}$，$s$ 为所选范数下的敏感度。

高维场景下，L2 敏感度远小于 L1，因此高斯机制加噪更少，更有优势。这是 DP-SGD 等机器学习算法选择高斯机制的重要原因。

## 8.5 灾难机制

### 定义

灾难机制 $F(q,x)$：

1. 从均匀分布 $U(0,1)$ 采样 $r$；
2. 如果 $r < \delta$，直接返回整个数据集 $x$；
3. 否则，返回 $q(x) + \operatorname{Lap}(s/\epsilon)$，其中 $s$ 是查询敏感度。

### 为什么满足 $(\epsilon, \delta)$-DP？

- 以概率 $1-\delta$，正常分支满足纯 $\epsilon$-DP；
- 以概率 $\delta$，灾难分支可以任意行为，定义中的 $+\delta$ 吸收了这种小概率失败。

因此它满足 $(\epsilon, \delta)$-DP，但显然不可接受。

### 意义

灾难机制说明 $(\epsilon, \delta)$-DP 定义本身允许小概率的灾难性失败。  
实际机制（如高斯机制）通常不会这样，而是“优雅失败”。  
因此选择机制时不能只看是否满足 $(\epsilon, \delta)$-DP，还要看失败时的行为。

## 8.6 高级组合

### 动机

普通顺序组合：$k$ 次 $(\epsilon, \delta)$-DP 组合后总隐私为 $(k\epsilon, k\delta)$，$\epsilon$ 线性增长，对迭代算法太悲观。

高级组合给出更紧的上界：$\epsilon'$ 约随 $\sqrt{k}$ 亚线性增长。

### 定理

如果 $k$ 个机制每个满足 $(\epsilon, \delta)$-DP，且是自适应组合，则对于任意 $\delta' > 0$，整体满足：

$$
(\epsilon',\ k\delta + \delta')\text{-DP}
$$

其中：

$$
\epsilon' = \epsilon \sqrt{2k \ln(1/\delta')} + k\epsilon(e^\epsilon - 1)
$$

当 $\epsilon$ 很小时（如 $\epsilon < 1$），近似为：

$$
\epsilon' \approx \epsilon \sqrt{2k \ln(1/\delta')}
$$

### 关键点

- $\epsilon'$ 约随 $\sqrt{k}$ 增长，而不是 $k$；
- $\delta$ 仍然线性累积：总失败概率为 $k\delta + \delta'$；
- 需要额外选择 $\delta'$，它影响 $\epsilon'$ 和总 $\delta$；
- 适用于自适应组合（后面的机制可依赖前面的输出）；
- 纯 $\epsilon$-DP 时 $\delta = 0$，公式退化为 8.5 节版本。

### 适用条件与失效情况

| 失效情况 | 原因 |
|----------|------|
| $k$ 很小（如 < 37） | $\epsilon'$ 可能比普通组合的 $k\epsilon$ 还大 |
| $\delta$ 不够小 | 总失败概率 $k\delta + \delta'$ 可能大到不可接受 |
| $\epsilon$ 较大 | 额外项 $k\epsilon(e^\epsilon - 1)$ 占主导，$\epsilon'$ 线性增长 |
| 要求纯 $\epsilon$-DP | 高级组合会引入 $\delta'$，不再是纯 DP |
| 机制本身不满足 DP | 前提不成立 |
| 并行组合场景 | 应使用并行组合定理，而非高级组合 |
| 现代隐私会计 | RDP/zCDP 通常更紧，高级组合不划算 |

### 与 RDP/zCDP 的关系

高级组合是承上启下的工具，后续第十章会介绍 Rényi 差分隐私（RDP）和零集中差分隐私（zCDP），它们能给出更紧的界，且 $\delta$ 不会像高级组合那样线性累积。实际 DP 机器学习（如 DP-SGD）常用 RDP/zCDP 做隐私会计。

## 8.7 与第七章裁剪的对应

第七章的裁剪用于控制标量/求和查询的敏感度，配合拉普拉斯机制，满足纯 $\epsilon$-DP。

第八章的向量值函数需要 L1/L2 敏感度，高斯机制可用 L2 敏感度，满足 $(\epsilon, \delta)$-DP。

对应关系：

| 第七章 | 第八章 |
|--------|--------|
| 标量查询 | 向量值查询 |
| 求和敏感度无界 | 向量 L2 敏感度无界 |
| 用 clipping 限制到 $[l, u]$ | 用 L2 clipping 限制 L2 范数到 $b$ |
| 敏感度变成 $u-l$ | L2 敏感度变成 $b$ |
| 拉普拉斯机制 | 高斯机制 |
| 满足纯 $\epsilon$-DP | 满足 $(\epsilon, \delta)$-DP |

L2 裁剪：

$$
\text{L2\_clip}(v, b) = \begin{cases}
b \cdot \frac{v}{\|v\|_2}, & \|v\|_2 > b \\
v, & \|v\|_2 \le b
\end{cases}
$$

裁剪后，向量值函数的 L2 敏感度为 $b$，然后可用高斯机制加噪。

**总结**：裁剪是“因”，有界敏感度是“果”，高斯机制是“工具”，近似差分隐私是“保证”。

## 总结

- 近似差分隐私 $(\epsilon, \delta)$-DP 允许以概率 $\delta$ 失败，$\delta$ 通常要求极小。
- 顺序组合：$\epsilon$ 和 $\delta$ 都相加；并行组合：$\epsilon$ 和 $\delta$ 取最大值；后处理不增加隐私损失。
- 高斯机制满足 $(\epsilon, \delta)$-DP，不满足纯 $\epsilon$-DP，因为密度比无全局上界。
- 高斯机制失败时是“优雅失败”：输出始终加噪，不会返回原始数据，只是隐私参数变弱。
- 向量值函数用 L1/L2 敏感度；高维时 L2 敏感度远小于 L1，高斯机制可用 L2，因此在高维场景更有优势。
- 灾难机制说明 $(\epsilon, \delta)$-DP 定义允许小概率灾难性失败，实际应选择优雅失败的机制。
- 高级组合让 $k$ 次组合的 $\epsilon'$ 约按 $\sqrt{k}$ 增长，但 $\delta$ 线性累积为 $k\delta + \delta'$。
- 高级组合在 $k$ 大、$\epsilon$ 小、$\delta$ 极小时有优势；$k$ 小、$\epsilon$ 大、要求纯 DP 或并行组合时可能失效。
- 第八章与第七章的裁剪通过“控制敏感度”对应：L2 裁剪使 L2 敏感度为 $b$，高斯机制据此加噪。

## Q&A

### 什么是近似差分隐私？

允许以概率 $\delta$ 失败的差分隐私，定义为 $\Pr[F(x) \in S] \le e^\epsilon \Pr[F(x') \in S] + \delta$。

### $\delta$ 的含义是什么？

$\delta$ 是失败概率。以概率 $1-\delta$，机制提供 $\epsilon$-DP 保证；以概率 $\delta$，可能不提供保证。

### 近似差分隐私的顺序组合如何计算？

$\epsilon$ 相加，$\delta$ 也相加：$(\epsilon_1+\epsilon_2, \delta_1+\delta_2)$-DP。

### 并行组合下 $\delta$ 如何处理？

取最大值：$\delta = \max_i \delta_i$，不累加。

### 高斯机制满足什么隐私？

满足 $(\epsilon, \delta)$-DP，不满足纯 $\epsilon$-DP。

### 为什么高斯机制不满足纯 $\epsilon$-DP？

高斯密度比在尾部无界，因为平方差展开后含有 $y$ 的一次项，无法像拉普拉斯那样用三角不等式消掉 $y$。

### 什么是优雅失败？

高斯机制失败时，输出仍然是加噪的，不会返回原始数据，只是隐私参数从 $\epsilon$ 变弱到稍大的 $\epsilon'$。

### 灾难机制是什么？

以概率 $\delta$ 直接返回整个数据集，以概率 $1-\delta$ 正常运行。它满足 $(\epsilon, \delta)$-DP，但不可接受。

### L1 和 L2 敏感度有什么区别？

L1 敏感度是各元素敏感度之和，随维度线性增长；L2 敏感度是平方和开根，随维度按平方根增长。高维时 L2 远小于 L1。

### 为什么高维下高斯机制更有优势？

高斯机制可用 L2 敏感度，拉普拉斯必须用 L1。高维时 L2 $\ll$ L1，所以高斯加噪更少。

### 高级组合的核心结论是什么？

$k$ 次 $(\epsilon, \delta)$-DP 组合后，$\epsilon' \approx \epsilon \sqrt{2k \ln(1/\delta')}$，$\delta$ 总为 $k\delta + \delta'$。

### 高级组合何时失效？

$k$ 小、$\delta$ 累积过大、$\epsilon$ 较大、要求纯 DP、并行组合、或使用 RDP/zCDP 更优时。

### 高斯机制与随机响应有何区别？

随机响应是本地模型、离散输出、通常纯 $\epsilon$-DP；高斯机制是中心模型、连续输出、$(\epsilon, \delta)$-DP，$\delta$ 是失败概率。

### 第八章与第七章裁剪如何对应？

第七章用 clipping 控制标量敏感度，配合拉普拉斯；第八章用 L2 clipping 控制向量 L2 敏感度，配合高斯机制。
