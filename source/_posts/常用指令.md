# hexo
创建文章： 
```bash 
hexo new "标题"
```

更新网站： 
```bash
git add .

git commit -m "更新"

git push origin main

hexo clean

hexo generate

hexo deploy
```

创建一个独立页面：
```bash
hexo new page 页面名称
```

列出所有文章（可以替换成页面，路由，标签，分类）:
```bash
hexo list post
```

# windows

强制刷新网页：
```
ctrl + shift + r
```
