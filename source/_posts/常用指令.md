# hexo
## 创建文章 
```bash 
hexo new "标题"
```

## 更新网站
```bash
git add .

git commit -m "更新"

git push origin main

hexo clean

hexo generate

hexo deploy
```

## 创建一个独立页面
```bash
hexo new page 页面名称
```

## 列出所有文章（可以替换成页面，路由，标签，分类）
```bash
hexo list post
```

# deepseek

## 启动deepseek harness
```bash
dsh web 
```

如果未安装可以先输入
```bash
nvm install 24.11.1 
nvm use 24.11.1
npm install -g @deepseek-ai/dsh
```
再执行上面的命令
