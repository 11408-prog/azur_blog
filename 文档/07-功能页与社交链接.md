### 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | 唯一标识，小写短横线 |
| `name` | ✅ | 显示名 |
| `description` | ✅ | `LocaleString`，至少填 `zh_CN`（缺了会回退 `en`，都缺就空白） |
| `icon` | ✅ | Iconify 格式，**新增名字要重启 dev**（见 [04](./04-图标图片与横幅.md)） |
| `category` | ✅ | `chat / coding / image / audio / video / writing / search / other` |
| `frequency` | ✅ | **`daily / weekly / occasional / experimental` 四选一**，不是随便写 |
| `url` | | 官网链接 |
| `usage` | | 一句话说明你拿它干什么 |
| `tags` | | 字符串数组 |
| `color` | | 卡片主题色，写十六进制 |

### 注意

- `frequency` 是**枚举**，写错会类型报错。想加新频率要先改文件顶部的 `AIToolFrequency` 联合类型
- DeepSeek Harness 归到 `coding`：它是 Agent 运行时框架，不是聊天工具
- 多个工具可以复用同一个图标

## 社交链接：放哪里

| 位置 | 文件 | 放什么 |
| --- | --- | --- |
| 导航栏「Links」下拉 | `src/config/navBarConfig.ts` | 外部社交 / 作品平台：GitHub、网易云音乐、Pixiv、X |
| 侧栏资料卡 | `src/config/profileConfig.ts` | 个人联系方式：Bilibili、酷狗概念版、GitHub、QQ、抖音 |

`navBarConfig` 里的外部链接必须写 `external: true`，否则会被 Swup 当成站内路由接管。

### 各平台链接怎么拿（都踩过坑，别瞎拼）

| 平台 | 能不能用账号 ID 拼 | 正确做法 |
| --- | --- | --- |
| Pixiv | ✅ | `pixiv.net/users/<纯数字ID>`，从地址栏复制 |
| GitHub / X / B 站 | ✅ | 直接拼用户名或数字 ID |
| QQ | ⚠️ 看要哪种效果 | 名片链接 `qm.qq.com/q/xxx`（手机 QQ 资料卡分享，兼容性最好）；`tencent://message/?uin=号码` 只有装了客户端才有效 |
| **抖音** | ❌ | 抖音号拼 `douyin.com/user/<抖音号>` 实测"用户不存在"。必须用 App 分享出来的**短链** `v.douyin.com/xxx`，再解析出 `sec_uid` |
| **酷狗** | ❌ | 个人主页只存在于 App 内，网页版账号中心需登录、没有公开 URL。改用它分享出来的**歌单**短链 `t1.kugou.com/xxx` |

**解析短链拿真实地址**（curl 跟随跳转即可）：

```bash
curl -s -o /dev/null -w "%{url_effective}\n" -L -A "Mozilla/5.0 (iPhone; ...)" "https://v.douyin.com/xxxx/"
```

抖音短链会跳到 `iesdouyin.com/share/user/MS4wLjABAAAA...`，取 `sec_uid` 那段拼成 `https://www.douyin.com/user/<sec_uid>`。**规范化的主页地址比短链稳定**，短链可能过期。

### 同一平台两处配置都要查

曾经出过：`navBarConfig` 里 B 站 ID 和 `profileConfig` 里的不一致，其中必有一个是错的（后来确认资料卡那个是错的）。
**改任何平台链接时，两个文件都搜一遍**，别只改一处。

## 其他功能页的开关

`featurePages` 里目前关闭的页面（番剧、项目、技能、时间线、设备）数据都是模板的假数据。
要启用，先在 `siteConfig.ts` 打开开关，再在 `navBarConfig.ts` 补菜单，并**替换成自己的数据**。
这几个页面的 `<script src="/js/...">` 还没改成 `withBase()`，启用前先看 [09](./09-路径与base.md)。
