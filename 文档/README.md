# 文档

本目录是这个博客（基于 Mizuki 模板的 Astro 站点）的维护文档。每篇只讲一件事，按需要查阅即可，不必从头读到尾。

> 文档记录的是**当前真实状态**。最后一次对照代码核实：2026-11-05。
> 改了源码、配置或流程，请同步更新对应的那一篇。

## 三十秒速览

| 项 | 值 |
| --- | --- |
| 线上地址 | <https://11408-prog.github.io/azur_blog/> |
| 框架 | Astro 7（静态输出）+ Svelte 5 + Tailwind CSS 4 + TypeScript |
| 模板 | Mizuki（完整博客模板，不是主题），改动见 [02](./02-项目结构与配置速查.md) |
| 包管理器 | **只能用 pnpm**（`preinstall` 里有 `only-allow pnpm`，npm / yarn 会直接失败） |
| 模块类型 | `"type": "module"`，所以根目录的辅助脚本要用 `.cjs` 后缀 |
| 文章数 | 43 篇（`src/content/posts/`） |
| 发布方式 | 本地构建后 **force push 到 `gh-pages` 分支**；`main` 分支放源码 |
| 站点路径 | 部署在子路径 `/azur_blog`，`base` 由 `siteURL` 自动推导 |

## 和 `docs/` 的关系

仓库根目录还有一个英文为主的 `docs/`，是 Mizuki 模板自带的文档（内容编写、渲染、内容仓库分离等）。
本目录 `文档/` 记录的是**这个站点自己的**配置、流程和踩过的坑，两者互不替代。
需要查模板的通用写法时，优先看 [`docs/CONTENT_AUTHORING.zh.md`](../docs/CONTENT_AUTHORING.zh.md)。
