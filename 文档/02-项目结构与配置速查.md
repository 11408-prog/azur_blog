# 02 项目结构与配置速查

## 目录结构

```
.
├── astro.config.mjs          Astro 主配置：site / base / 插件链 / Markdown 处理器 / Swup
├── package.json
├── pnpm-workspace.yaml       含 nodeLinker: hoisted（原因见 01）
├── pagefind.yml              搜索索引配置
├── public/                   静态资源，原样拷贝到 dist 根目录
│   ├── img/                  从旧站迁来的图片（头像、封面等）
│   ├── images/albums/        相册图片和每个相册的 info.json
│   ├── assets/               横幅等资源
│   ├── favicon/              浏览器标签页图标
│   └── music/                本地 mp3（已 gitignore，用脚本重建）
├── src/
│   ├── config/               ★ 所有站点配置集中在这里（19 个文件）
│   ├── content/
│   │   ├── posts/            ★ 文章，按子目录分类
│   │   └── spec/             独立页面内容：about.md、friends.md
│   ├── content.config.ts     ★ front matter 的 Zod schema
│   ├── data/                 ai-tools.ts、diary.ts 等数据文件
│   ├── pages/                路由文件，一个 .astro 一个页面
│   ├── components/           组件（organisms / widgets / features 等分层）
│   ├── layouts/              页面骨架
│   ├── plugins/              remark / rehype 插件
│   ├── scripts/              客户端脚本（Swup、Fancybox 等）
│   ├── styles/               全局样式
│   ├── i18n/                 多语言文案
│   ├── utils/                工具函数（含文章加密）
│   └── assets/               字体、默认图片，以及 public 的"影子副本"（见 04）
├── scripts/                  构建辅助脚本
├── tests/                    测试
├── docs/                     Mizuki 模板自带文档
├── 文档/                     本站自己的维护文档（就是这里）
├── deploy-pages.ps1          构建并推送到 gh-pages
├── deploy.bat                deploy-pages.ps1 的双击入口
├── auto-deploy.cmd           一键部署 + 提交并推送源码
├── build-and-open.ps1        构建并打开预览
└── start-site.bat            build-and-open.ps1 的双击入口
```

## 内容集合

`src/content/` 下有两个集合：

| 集合 | 用途 | 路径 |
| --- | --- | --- |
| `posts` | 文章 | `src/content/posts/**/*.{md,mdx}` |
| `spec` | 独立页面内容（无 schema 约束） | `src/content/spec/**` |

`spec` 里现在有：

- `about.md`：**关于页的内容**（`src/pages/about.astro` 通过 `getEntry("spec", "about")` 读取）
- `friends.md`：**友链页内容，目前是空文件**，而友链页是开启的，所以线上是个空页面

改关于页或友链页只要改这两个 Markdown，不用碰 `.astro`。

## 导航栏现状

```
首页  归档  分类  标签
Links  →  GitHub / 网易云音乐 / Pixiv / X
My     →  Diary / Gallery
About  →  About / Friends
Others →  AITools
```

**分工约定**：外部社交平台放「Links」下拉，个人联系方式放资料卡。
已经删掉的菜单项：Anime、Devices、Projects、Skills、Timeline。想加回来，先在 `siteConfig.ts` 的 `featurePages` 里打开对应开关，再在 `navBarConfig.ts` 补上菜单。

## 改过的模板源码

配置文件的改动丢了还能重配，但下面这些是**直接改了模板源码**。升级 Mizuki 时会被覆盖，升级前务必先备份、对照，升级后重新打补丁。

| 文件 | 改了什么 | 丢了会怎样 |
| --- | --- | --- |
| `src/components/organisms/navigation/Navbar.astro` | 图标加了 `iconSrc ?` 判断，为空不渲染（顶栏支持纯文字）；首页判断先剥掉 `base` | 图标留空会渲染空 `src` 的 `<img>`；子路径下首页不高亮 |
| `src/components/widgets/site-stats/SiteStats.astro` | 运行天数按自然日计算（`Math.floor` + 两端归零） | 天数每天多显示 1 天 |
| `src/components/widgets/music-player/constants.ts` | `LOCAL_PLAYLIST` 改为从 `localPlaylist.generated` 导入；封面也过 `withBase` | 播放器读不到歌单、封面空白 |
| `src/layouts/MainGridLayout.astro` | 首页判断先剥掉 `base` | 线上横幅标题和打字机不显示 |
| `src/utils/album-scanner.ts` | 相册图片路径过 `withBase` | 相册详情页满屏破图 |
| `src/pages/404.astro`、`src/pages/albums/[id]/index.astro` 等 | 手写的根路径改用 `withBase()` | 线上跳转到域名根或 404 |
| `src/utils/crypto-utils.ts`、`src/components/features/auth/*` | 加密协议改为随机 salt / IV，迭代次数提到 60 万（见 [12](./12-安全.md)） | 回到有 nonce 复用风险的旧实现 |
| `scripts/check-global-style-loading.mjs`、`scripts/sync-content.js` | 支持 `base` 前缀；命令改为参数数组；默认关闭同步 | `pnpm build` 在子路径下失败 |

新增改动后，记得同步更新这张表。
