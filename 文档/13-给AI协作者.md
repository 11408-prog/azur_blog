# 13 给 AI 协作者

> 如果你是帮忙改这个仓库的 AI 助手：动手之前先读完这一页，再读和任务相关的那一篇。

## 基本原则

1. **先读文档，再看 `src/config/`，最后才动组件**。Mizuki 的配置覆盖度很高，**改配置优先于改组件**
2. **不要动旧站目录**（旧 Hexo 站点，是 git 仓库，用户明确要求保留）
3. **改完源码，同步更新 `文档/` 里对应的那一篇**，尤其是 [02](./02-项目结构与配置速查.md) 里的"改过的模板源码"表
4. **不要替用户执行这些事**：构建、预览、部署、大批量删除、`tools-convert-albums.mjs`。这些请让用户在自己的终端里运行（原因见 [10](./10-排障与环境问题.md)）
5. 不要提交或回显任何凭据。`.deploy-token`、`.env` 里的内容不要打印出来

## 容易踩的坑

| 场景 | 要点 |
| --- | --- |
| 新增文章 | `tags` 里的纯数字要加引号（`"408"`）；分类是单值 |
| 新增或修改图标 | 只能用 6 个本地集合；改完要**重启 dev**，不是配置写错了 |
| 换图片 | `public/` 和 `src/assets/public/` 影子副本要**同时换**；清 `node_modules/.astro` 缓存；别把 `.jpg` 直接改名成 `.webp` |
| 写站内路径 | 以 `/` 开头的一律用 `withBase()`；判断首页要先剥 base |
| 改 `build-and-open.ps1` | 保持纯英文 + UTF-8 BOM |
| 改 `start-site.bat` | `echo` 里不能有裸的 `>` `<`；不要删末尾的 `pause` |
| 改音乐同步脚本 | 别破坏三个安全设计，尤其是"数量骤降就中止" |
| 改加密模块 | 不要让 salt / IV 回到确定性派生；常量只在 `CRYPTO_CONSTANTS` 里改 |
| 命令 | 用 `pnpm`，不要用 npm / yarn；PowerShell 里不能写 `VAR=value cmd` |

## 提交前自检

```bash
pnpm lint                                              # Biome（只检查 src/）
pnpm check                                             # astro check
node --experimental-strip-types tests/crypto.test.mjs  # 加密测试
pnpm test                                              # 注意：有 3 项已知失败，见 10
```
