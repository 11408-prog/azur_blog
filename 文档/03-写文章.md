# 03 写文章

## 新建文章

在 `src/content/posts/` 下按分类建子目录，然后放 `.md` 文件。**目录名是分类的一部分，也决定 URL**。

```
src/content/posts/python/某篇笔记.md   →   /posts/python/某篇笔记/
```

也可以用 `pnpm new-post`（`scripts/new-post.js`）。

## front matter 字段

定义在 `src/content.config.ts` 的 `postsCollection`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | string | ✅ | 标题 |
| `published` | date | ✅ | 发布日期，写 `2026-10-24` |
| `updated` | date | | 更新日期 |
| `category` | string | | **单分类**，Mizuki 不支持多值 |
| `tags` | string[] | | 标签数组 |
| `description` | string | | 摘要 |
| `image` | string | | 封面图路径 |
| `draft` | boolean | | 默认 `false`，草稿不会发布 |
| `pinned` | boolean | | 置顶 |
| `comment` | boolean | | 默认 `true`，可以单篇关闭评论 |
| `priority` | number | | 置顶文章之间的排序优先级 |
| `lang` | string | | 文章语言，留空则用站点语言 |
| `hideHomeContent` | boolean | | 在首页和列表里隐藏摘要；设置了密码时默认隐藏 |
| `author` / `sourceLink` / `licenseName` / `licenseUrl` | string | | 转载来源与授权 |
| `encrypted` / `password` / `passwordHint` | boolean / string / string | | 加密文章，见下文 |
| `permalink` | string | | 自定义链接，优先级最高 |
| `alias` | string | | 链接别名 |

示例：

```yaml
---
title: "操作系统笔记"
published: 2026-10-24
category: "408"
tags: ["408", "操作系统"]
description: "考研 408 操作系统复习笔记"
image: "/img/covers/xxx.jpg"
---
```

更多写法（提示块、图片、折叠块、数学公式、Mermaid 等）见模板文档 [`docs/CONTENT_AUTHORING.zh.md`](../docs/CONTENT_AUTHORING.zh.md)。

## 写 front matter 的三个坑

1. **纯数字标签必须加引号**。`tags: [408]` 会被 YAML 解析成数字，违反 `z.array(z.string())`，**导致整站构建失败**。必须写 `tags: ["408"]`。
2. **别用中文逗号**。迁移脚本当时按 `/[,，]/` 同时处理了中英文逗号，手写时请统一用英文逗号。
3. **分类是单值**。旧站的 `categories` 可能是多值，迁过来只取了第一个。

## 链接是怎么生成的

由 `src/config/permalinkConfig.ts` 控制，默认是 `/posts/{文件路径}/`。
旧站的 `/2026/08/11/标题/` 格式链接在新站**全部失效**，目前还没有做重定向（见 [11](./11-迁移记录与待办.md)）。

## 加密文章

```yaml
encrypted: true
password: "一个足够长的密码"
passwordHint: "给读者的可选提示"
```

两点必须知道：

- **这不是访问控制**。文章在构建时被加密，读者在浏览器里输入密码后解密。加密后的内容仍然随静态站点公开分发，任何人都可以下载密文并离线尝试破解，所以请使用**长密码**，并且不要用它存放凭据、私钥或高度敏感的内容。
- **仓库源码里是明文**。`password` 和正文都写在 `.md` 里，而这个仓库是公开的，所以**任何人都能在 GitHub 上直接看到密码和原文**。加密只保护构建出来的网页，不保护仓库。如果文章确实需要保密，请不要把它提交到公开仓库。

加密文章不会进入 RSS / Atom。加密细节和已修复的漏洞见 [12 安全](./12-安全.md)。

相册也支持密码，写在相册目录的 `info.json` 里（`"password": "..."`）。

## 关于页和友链页

内容分别在 `src/content/spec/about.md` 和 `src/content/spec/friends.md`，改它们不用碰 `.astro`。
`friends.md` 目前是空的，而友链页是开启的，需要补内容，或者在 `siteConfig.ts` 的 `featurePages.friends` 里关掉。

## 构建时的无害警告

构建时会出现下面的提示，可以忽略：

```
[astro-expressive-code] Error while highlighting code block using language "conf"
[astro-expressive-code] Error while highlighting code block using language "C"
```

Shiki 不认识 `conf` 和 `C` 这两个语言标识，会自动降级成纯文本。涉及文章：`linux/Arch-Linux-Hyprland-配置操作留档.md`、`408/数据结构/线性表笔记.md`。想要高亮就把代码围栏语言改成 `ini` / `c`。
