通信层

2.1.1 通信基础的基本概念

1. 基本概念

  • 信源：信号来源，即数据的发送方。
  • 信宿：信号的“归宿”，即数据的接收方。

2. 信号与信道

  • 信号：数据的载体。
    • 模拟信号：值是连续的（如正弦波）。
    • 数字信号：值是离散的（如方波）。
  • 信道：信号的通道（传输介质）。
    • 模拟信道：适用于传输模拟信号。
    • 数字信道：适用于传输数字信号。

3. 码元

  • 定义：每一类信号就是一个码元。一个“信号周期”内的波形对应一个码元。
  • 码元宽度：指一个“信号周期”的持续时间长度。
  • 进制（K进制）：若一个周期内可能出现 K 种不同的信号（状态），则称为 K进制码元。
  • 信息量计算：1个码元携带的信息量为 (\log_2 K) （单位：比特，bit）。

4. 速率（核心指标）

  • 波特率（调制速率）：
    • 定义：每秒传输几个码元。
    • 单位：码元/秒 或 波特（Baud）。
  • 比特率（信息传输速率）：
    • 定义：每秒传输几个比特。
    • 单位：bit/s（或 b/s， bps）。

5. 内在联系（重点公式）

比特率 = 波特率 × 每个码元携带的比特数

即：
[
\text{比特率} = \text{波特率} \times \log_2 K
]
（其中 (K) 为码元的进制数，即一个码元携带 (\log_2 K) 个比特）

  • 带宽（W）：信道允许通过的信号频带范围。单位：Hz。
  • 噪声：噪声会影响信道的数据传输效果，导致信号失真。

2.1.3_1 编码和调制（上）

1. 基本概念

  • 编码与解码：
    • 编码：将数字数据转换为数字信号的过程。
    • 解码：将数字信号还原为数字数据的过程。
  • 调制与解调：
    • 调制：将数字数据转换为模拟信号的过程。
    • 解调：将模拟信号还原为数字数据的过程。
  • 核心区别：
    • 编码：数字数据 数字信号（适用于基带传输）。
    • 调制：数字数据 模拟信号（适用于频带传输，需通过载波传输）。

2. 常用的编码方法（数字信号编码）

参考波形示例：二进制数据 1 1 1 1 0 0 1 0 1

2.1 不归零编码（NRZ）

  • 规则：低电平表示 0，高电平表示 1，码元中间不跳变（中不变）。
  • 特点：
    • 自同步能力：无。
    • 浪费带宽：不浪费。
    • 抗干扰能力：弱。
    • 缺点：无法自带同步信号，连续相同比特时接收方难以提取时钟信号。

2.2 归零编码（RZ）

  • 规则：低电平表示 0，高电平表示 1，每个码元传输结束后必须回到零电平（中归零）。
  • 特点：
    • 自同步能力：有。
    • 浪费带宽：浪费。
    • 抗干扰能力：弱。
    • 缺点：由于每个码元都要归零，导致信号频率变高，需要占用更多带宽。

2.3 反向非归零编码（NRZI）

  • 规则：看起点，信号电平跳变表示 0，电平不跳变表示 1，码元中间不跳变（跳0不跳1看起点，中不变）。
  • 特点：
    • 自同步能力：若增加冗余位（例如 8+1 bit），可支持自同步。
    • 浪费带宽：浪一点，但不多。
    • 抗干扰能力：弱。
    • 总结：依赖相对变化传递信息，相比于 NRZ 抗干扰能力略强，但仍未彻底解决同步问题。

2.4 曼彻斯特编码（Manchester Encoding）

  • 规则：每个码元正中间必定发生电平跳变（中必变）。跳变既作为数据信号又作为时钟信号。约定：跳0反跳1看中间（例如：上0下1，即高到低表示 0，低到高表示 1）。
  • 特点：
    • 自同步能力：有。
    • 浪费带宽：浪费（波特率是数据率的 2 倍，即需要 2Hz 的带宽）。
    • 抗干扰能力：强。
    • 总结：应用极广（如传统以太网），牺牲带宽换取自同步能力。

2.5 差分曼彻斯特编码（Differential Manchester Encoding）

  • 规则：每个码元正中间始终发生电平跳变（中必变，仅用于时钟同步）。数据由码元起始边界是否发生跳变决定：跳0不跳1看起点（起始边界有跳变表示 0，无跳变表示 1）。
  • 特点：
    • 自同步能力：有。
    • 浪费带宽：浪费（同样波特率是数据率的 2 倍，需要 2Hz 带宽）。
    • 抗干扰能力：强（比曼彻斯特编码更强）。
    • 总结：结合了 NRZI 和曼彻斯特编码的优点，常用于令牌环网。

3. 各种编码的特点对比总结

4. 考点提示

  • 频带宽度计算：曼彻斯特编码和差分曼彻斯特编码的波特率是比特率的 2 倍。若比特率为 ，则波特率为 ，所需信道带宽至少为 （或根据具体定义变化）。
  • 自同步能力：信源和信宿可以根据信号完成“节奏同步”，无需额外时钟信号。有自同步能力的编码：RZ、曼彻斯特、差分曼彻斯特。
  • 差分编码的优势：差分曼彻斯特和 NRZI 均属于差分信号，依靠电平的相对变化传递信息，抗共模干扰能力更强。

2.1.3_2 编码和调制（下）

1. 调制的基本概念

  • 基带信号：来自信源的数字信号，需经过调制后才能在特定信道上传输。
  • 调制：将数字数据转换为模拟信号的过程，以便在模拟信道（如电话线、无线信道）中传输。
  • 解调：将模拟信号还原为数字数据的过程。
  • 核心目标：让一个码元携带更多的比特，提高数据传输速率。

4. 知识回顾与重要考点总结

4.1 概念辨析

  • 编码：二进制数据 数字信号，逆过程称为“解码”。
  • 调制：二进制数据 模拟信号，逆过程称为“解调”。

4.2 编码技术核心口诀

  • 不归零编码（NRZ）：低0高1，中不变。
  • 归零编码（RZ）：低0高1，中归零。
  • 反向非归零编码（NRZI）：跳0不跳1看起点，中不变。
  • 曼彻斯特编码：跳0反跳1看中间，中必变。
    • 考研常见标准：上0下1（高到低表示0，低到高表示1）。
    • 另一种标准：下0上1。
  • 差分曼彻斯特编码：跳0不跳1看起点，中必变。

4.3 调制技术核心公式

  • 调幅（AM）或幅移键控（ASK）：若信号波有 种振幅，则 1码元 = bit。
  • 调频（FM）或频移键控（FSK）：若信号波有 种频率，则 1码元 = bit。
  • 调相（PM）或相移键控（PSK）：若信号波有 种相位，则 1码元 = bit。
  • 正交幅度调制（QAM）：AM与PM结合，形成叠加信号。若有 种振幅、 种相位，则 1码元 = bit。

2.2 传输介质

传输介质是数据传输系统中在发送设备和接收设备之间的物理通路，分为导向型介质（有线）和非导向型介质（无线）。

1. 导向型介质（有线）

核心特性：从上至下（双绞线 → 同轴电缆 → 光纤），抗干扰能力依次增强，信号传输损耗依次降低。

1.1 双绞线 (Twisted Pair)

  • 结构：两根导线相互绞合而成（绞合是为了抵消电磁干扰）。
  • 分类：
    • 屏蔽双绞线 (STP)：有屏蔽层，抗干扰能力更强，价格较贵。
    • 非屏蔽双绞线 (UTP)：没有屏蔽层，便宜、易安装，广泛用于以太网和电话线。

1.2 同轴电缆 (Coaxial Cable)

  • 结构：内导体 + 外导体屏蔽层。
  • 作用：
    • 内导体：用于传输信号。
    • 外导体屏蔽层：用于抗电磁干扰。

1.3 光纤 (Optical Fiber)

  • 结构：纤芯（高折射率） + 包层（低折射率）。
  • 原理：利用光的全反射特性，在纤芯内传输光脉冲信号。
  • 分类与对比：
    类型 传输方式 适用距离 传输损耗 特点
    单模光纤 只有一条光线在一根光纤中传输 长距离 小 频带宽、容量大、抗干扰强，但光源贵（需激光器）
    多模光纤 多条光线在一根光纤中传输 近距离 较大 远距离传输光信号容易失真，光源便宜（可用LED）

2. 无线传输介质

  • 本质：无线传输介质本质上都是电磁波，只是波长不同而已（长波 → 短波）。
  • 波长与频率：波长和信号频率呈反比。
  • 特性对比：
    • 短波：信号指向性强、数据传输能力强。
    • 长波：信号绕射性好、指向性弱。
  • 考点提示：卫星通信属于短波（或微波）通信。

3. 物理层接口的特性

物理层接口定义了DTE和DCE之间的物理连接规范，包含四大特性：

  • 机械特性：指明接口所用接线器的形状和尺寸、引脚数目和排列、固定和锁定装置等。
  • 电气特性：指明在接口电缆的各条线上出现的电压的范围、传输速率、距离限制等。
  • 功能特性：指明某条线上出现的某一电平的电压的意义。
  • 过程特性（规程特性）：指明对于不同功能的各种可能事件的出现顺序。

2.3 物理层设备

1. 中继器 (Repeater)

  • 端口数量：只有两个端口。
  • 工作原理：通过一个端口接收信号，将失真信号整形再生，并转发至另一端口（会产生一些时延）。
  • 通信模式：仅支持半双工通信（两端连接的结点不可同时发送数据，否则会导致“冲突”）。
  • 网段：中继器两个端口对应两个“网段”。

2. 集线器 (Hub)

  • 本质：本质上是多端口中继器。
  • 工作原理：集线器将其中一个端口接收到的信号整形再生后，转发到所有其他端口。
  • 通信模式：各端口连接的结点不可同时发送数据，会导致“冲突”。（属于共享式设备）
  • 冲突域：集线器的N个端口对应N个“网段”，各网段属于同一个“冲突域”。（即所有连在Hub上的设备都在同一个冲突域内）。

3. 物理层设备的一些特性

  • 串联限制：集线器、中继器不能“无限串联”（受限于信号传播时延和冲突域范围）。
  • 拓扑结构：集线器连接的网络，物理上是星形拓扑，逻辑上是总线型拓扑。
  • 带宽共享：集线器连接的各网段**“共享带宽”**（例如：10Mb/s的集线器，如果有10台电脑同时用，平均每台大概只有1Mb/s）。
  • 介质与协议兼容：

    集线器可以连接不同的传输介质，因此两个网段的物理层接口特性可以不同（这就意味着集线器连接的网段，“物理层协议”可以不同）。

  • 速率兼容：

    集线器如果连接了速率不同的网段，会导致所有网段**“速率向下兼容”**（即高速设备会降速到低速设备的速率）。

笔记补充提示：

  1. 物理层设备（中继器、集线器）无法隔离冲突域（只有数据链路层的网桥/交换机才能隔离冲突域）。
  2. 集线器由于是广播式转发，所有端口共享同一个冲突域，且不隔离广播域。
