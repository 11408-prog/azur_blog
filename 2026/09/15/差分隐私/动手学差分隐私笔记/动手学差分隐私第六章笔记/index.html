6.2.1 直方图（Histograms）

直方图是并行组合的典型应用。

  • 直方图按某个属性的不同取值分箱，例如按“教育程度”统计人数。
  • 每个 bin 对应一个属性值（如 HS-grad、Bachelors、Masters 等）。
  • 一行数据不可能同时属于两个 bin，因此这些 bin 是不相交的。
  • 对每个 bin 的计数加 Laplace 噪声并发布，总隐私成本仍然是 ，而不是 （ 为 bin 的数量）。

代价：

  • bin 分得越细，每个 bin 的计数越小，信号越弱。
  • 加同样的噪声，相对误差越大，结果精度下降。
  • 并行组合让隐私成本不随分组数量增长，但效用会随分组变细而下降。

6.2.2 列联表（Contingency Tables）

列联表是多维直方图，例如同时按教育程度和性别统计人数。

  • 每个个体只落入一个单元格。
  • 单元格之间不相交，因此也能使用并行组合。
  • 总隐私成本仍然是 。
  • 同样，随着维度增加，每个单元格计数变小，噪声相对更强，精度下降。

意义

  • 对差分隐私输出做任意后处理，都不会破坏隐私保证，也不会增加隐私成本。
  • 可以放心地对结果进行降噪、平滑、取整、排序、可视化、再计算等操作。
  • 后处理不能逆转隐私保护，也不能降低已经消耗的隐私预算。

与并行组合的顺序区别

  • 先划分输入，再分别运行 DP → 并行组合 → 总隐私成本 ，可节省预算。
  • 先整体运行 DP，再划分输出 → 后处理 → 总隐私成本还是整体机制的 ，不能套用并行组合来降低隐私成本。
  • 两者顺序不能混用，否则会错误核算隐私预算。

6.5 常见误解与澄清

并行组合算不算后处理？

不算。并行组合要求先划分输入数据，再分别运行机制；后处理是对已经发布的 DP 输出再做加工。两者形式不同，依赖的定理也不同。

顺序变了会有什么影响？

  • 先划分输入再分别 DP → 并行组合 → 总成本 。
  • 先整体 DP 再划分输出 → 后处理 → 总成本仍为整体机制的 。
  • 如果对划分后的每个部分重新运行新的 DP 机制，则变成顺序组合，隐私成本会叠加。

为什么顺序组合给出 ？

因为顺序组合假设每次机制都访问全部数据，每个个体被访问 次，隐私损失累加。

为什么并行组合给出 ？

因为每个个体只出现在一个子集中，只被机制访问一次，隐私成本不累加。

直方图并行组合是不是把数据分成 份？

不是。数据按属性的不同取值分成 个不相交子集，通常 远小于 （ 为总行数）。如果分成 份，每个子集只有一行，噪声会完全淹没信号，结果不可用。

总结

  • 顺序组合：同一数据集上多次运行机制，隐私预算相加。给出保守上界，实际损失可能更小。
  • 并行组合：数据集划分成不相交子集，分别运行机制，总隐私成本取最大值（通常为 ），不随子集数量线性增长。
  • 后处理：对 DP 输出做任意加工，隐私保证不变，不增加隐私成本。
  • 三个性质共同支撑差分隐私算法的设计与隐私预算核算。
  • 并行组合不是免费的：分组越细，每个子集数据越少，相对噪声越大，效用越差。

Q&A

顺序组合和并行组合最本质的区别是什么？

顺序组合中每次机制都访问全部数据，每个个体被访问多次，隐私成本相加；并行组合中数据被分成不相交子集，每个个体只被访问一次，隐私成本取最大值。

为什么顺序组合给出的 是上界，可能不紧？

因为顺序组合考虑最坏情况，实际机制组合后的输出分布可能比最坏情况更接近，实际隐私损失可能小于预算之和。书中 F_combined 的例子说明了这一点。

后处理会消耗隐私预算吗？

不会。后处理对已经满足差分隐私的输出进行任意计算，仍然满足相同的差分隐私保证，不增加隐私成本。

直方图为什么能用并行组合？

因为直方图的每个 bin 对应一个属性值，一行数据只能属于一个 bin，bin 之间不相交，满足并行组合的条件。

列联表也能用并行组合吗？

能。列联表是多维直方图，每个个体只落入一个单元格，单元格之间不相交，因此总隐私成本仍为 。

并行组合中，如果不同子集使用不同的 ，总隐私成本是多少？

纯差分隐私下，隐私预算一定大于等于隐私损失吗？

是的。纯 -差分隐私要求隐私损失不超过 ，即预算大于等于损失。但注意是“小于等于”，不是“严格小于”。

近似差分隐私下，预算一定大于等于损失吗？

不能无条件说。只能说以至少 的概率隐私损失不超过 ，有 的概率可能超过。
